## Answer

Orca supports Pi directly, not only OMP. It delivers conversation prompts and worker instructions to Pi, and offers persistent global skills. The inspected launch paths do not replace Pi's system prompt. Default skill selections are not evidence of silent installation on every Pi launch.

## Prompt delivery

- **Normal launch:** Pi uses positional prompt arguments. The launch builder quotes the supplied prompt and appends it to the command. An empty launch adds no prompt. Sources: [`src/shared/tui-agent-config.ts:166–179`](https://github.com/stablyai/orca/blob/31012aeb09283dc901a2c7417747e5a081f33cbf/src/shared/tui-agent-config.ts#L166-L179), [`src/shared/tui-agent-startup.ts:84–117`](https://github.com/stablyai/orca/blob/31012aeb09283dc901a2c7417747e5a081f33cbf/src/shared/tui-agent-startup.ts#L84-L117).
- **Draft launch:** Pi receives `ORCA_PI_PREFILL`; OMP receives `ORCA_OMP_PREFILL`. The draft builder places the text in the child environment and adds cleanup after the command. These variables carry editor drafts, not a system prompt. Source: [`src/shared/tui-agent-startup.ts:249–282`](https://github.com/stablyai/orca/blob/31012aeb09283dc901a2c7417747e5a081f33cbf/src/shared/tui-agent-startup.ts#L249-L282).
- **Supervised worker:** Orca builds a preamble containing coordinator identity, task/dispatch IDs, reporting commands, heartbeat rules, questions, and task text. Terminal workers receive it through `sendTerminalAgentPrompt`, not a global instruction file. Sources: [`src/main/runtime/orchestration/preamble.ts:52–145`](https://github.com/stablyai/orca/blob/31012aeb09283dc901a2c7417747e5a081f33cbf/src/main/runtime/orchestration/preamble.ts#L52-L145), [`deliver-worker-dispatch-preamble.ts:39–79`](https://github.com/stablyai/orca/blob/31012aeb09283dc901a2c7417747e5a081f33cbf/src/main/runtime/rpc/methods/orchestration/worker/deliver-worker-dispatch-preamble.ts#L39-L79). The common transport constructs bracketed-paste bytes. OMP specifically joins Enter to the paste frame: [`src/shared/agent-prompt-injection.ts:16–19,128–136`](https://github.com/stablyai/orca/blob/31012aeb09283dc901a2c7417747e5a081f33cbf/src/shared/agent-prompt-injection.ts#L16-L19).
- **Coordinator:** The current flow uses a skill guide plus Run/task/worker commands. Legacy automatic `coordinator-start` and `coordinator-stop` reject requests without effects: [`src/cli/handlers/orchestration/dispatch-handlers.ts:73–85`](https://github.com/stablyai/orca/blob/31012aeb09283dc901a2c7417747e5a081f33cbf/src/cli/handlers/orchestration/dispatch-handlers.ts#L73-L85). Do not describe the retired automatic coordinator as current behavior.

OMP also gets a launch-specific `--config` file containing `autoResume: false`. This is session control, not injected instructions, and the builder applies it only to OMP: [`src/shared/omp-fresh-launch.ts:4–24,49–57`](https://github.com/stablyai/orca/blob/31012aeb09283dc901a2c7417747e5a081f33cbf/src/shared/omp-fresh-launch.ts#L4-L24), [`src/shared/tui-agent-startup.ts:76–77`](https://github.com/stablyai/orca/blob/31012aeb09283dc901a2c7417747e5a081f33cbf/src/shared/tui-agent-startup.ts#L76-L77).

## Skills: defaults, installation, and paths

The default onboarding selections are `orca-cli`, `computer-use`, and `orchestration`. `orca-linear` is not selected. The selection builds an interactive `npx skills add https://github.com/stablyai/orca ... --global` command. The setup flow copies that command and presents it for review, rather than silently installing it. The skill terminal explicitly says “Press Enter to install.” Sources: [`onboarding-feature-setup.ts:37–61,121–130,304–336`](https://github.com/stablyai/orca/blob/31012aeb09283dc901a2c7417747e5a081f33cbf/src/renderer/src/components/onboarding/onboarding-feature-setup.ts#L37-L61), [`AgentCapabilitiesSetupAction.tsx:94–120`](https://github.com/stablyai/orca/blob/31012aeb09283dc901a2c7417747e5a081f33cbf/src/renderer/src/components/feature-wall/AgentCapabilitiesSetupAction.tsx#L94-L120), [`CliSkillSetupTerminal.tsx:81–95`](https://github.com/stablyai/orca/blob/31012aeb09283dc901a2c7417747e5a081f33cbf/src/renderer/src/components/feature-tips/CliSkillSetupTerminal.tsx#L81-L95).

The explicit headless command, `orca skills install`, runs noninteractive installation. It targets detected agents plus `universal`, unless `--agent` overrides that selection. Pi maps to `--agent pi`; OMP has no dedicated community-installer mapping and uses the shared target. Global scope is the default; `--local` selects project scope. Sources: [`src/shared/skills-cli-agent-keys.ts:24–26,63–94`](https://github.com/stablyai/orca/blob/31012aeb09283dc901a2c7417747e5a081f33cbf/src/shared/skills-cli-agent-keys.ts#L24-L26), [`src/cli/handlers/skills.ts:120–192,237–240`](https://github.com/stablyai/orca/blob/31012aeb09283dc901a2c7417747e5a081f33cbf/src/cli/handlers/skills.ts#L120-L192).

Orca's scanner explicitly recognizes `~/.agents/skills`, `~/.pi/agent/skills`, and `~/.omp/agent/skills`: [`src/main/skills/skill-discovery-sources.ts:69–76,111–126`](https://github.com/stablyai/orca/blob/31012aeb09283dc901a2c7417747e5a081f33cbf/src/main/skills/skill-discovery-sources.ts#L69-L126). These are persistent skill homes, not a temporary Orca-session overlay. The external `skills` package owns the exact copy/symlink operation; this investigation did not execute or audit that package.

Installed Orca skills are short discovery stubs. They tell the agent to resolve the session's CLI, then request the version-matched guide with `orca skills get`. The orchestration stub includes coordination instructions and guide-loading rules: [`skills/orchestration/SKILL.md:14–66`](https://github.com/stablyai/orca/blob/31012aeb09283dc901a2c7417747e5a081f33cbf/skills/orchestration/SKILL.md#L14-L66). Installation does not mean that every guide is appended to every Pi system prompt.

## Controls and limits

The setup selections can be cleared, and the interactive installation can be skipped. The launch-specific prompt and supervised-worker preamble depend on the requested launch or dispatch. The orchestration setup UI stores `orca.orchestration.enabled`, but this inspection does not establish that UI marker as an enforced runtime permission gate: [`orchestration-setup-state.ts:1–15`](https://github.com/stablyai/orca/blob/31012aeb09283dc901a2c7417747e5a081f33cbf/src/renderer/src/lib/orchestration-setup-state.ts#L1-L15).

No writes to Pi's `AGENTS.md`, `SYSTEM.md`, `APPEND_SYSTEM.md`, or `settings.json` were established by these prompt/skill paths. This is a scoped finding, not a repository-wide guarantee. Custom Pi directories and the external installer's exact handling of them remain unverified. Both Pi and OMP use the `PI_CODING_AGENT_DIR` contract, but Orca keeps their source-directory shadows distinct: [`src/shared/pi-agent-kind.ts:5–27`](https://github.com/stablyai/orca/blob/31012aeb09283dc901a2c7417747e5a081f33cbf/src/shared/pi-agent-kind.ts#L5-L27).

Public documentation corroborates skill defaults and worker preambles: [skills](https://www.onorca.dev/docs/cli/skills), [orchestration](https://www.onorca.dev/docs/cli/orchestration). Its discovery list omits Pi, while the pinned source explicitly includes Pi. Source takes precedence.
